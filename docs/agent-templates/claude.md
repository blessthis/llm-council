# Claude Code — Subagent Template

Derived from pi canonical. Closest sibling format — only differences are tool name casing + `model: inherit` keyword.

## File paths

- **User-level:** `~/.claude/agents/<name>.md`
- **Project-level:** `<repo>/.claude/agents/<name>.md`

## Frontmatter schema (YAML)

| Key | Type | Required | Notes |
|------|------|----------|-------|
| `name` | string | ✅ | kebab-case |
| `description` | string (folded `>-` ok) | ✅ | Auto-routing |
| `tools` | comma-list (**TitleCase**) | ✅ | TitleCase built-ins + `mcp__<server>__<tool>` |
| `model` | string | ❌ | `model: inherit` IS valid here (unlike pi). Omit also inherits. |

### Tool name conventions

- **Built-ins:** TitleCase — `Read, Write, Edit, Grep, Glob, Bash, WebSearch, WebFetch`
- **MCP:** `mcp__<server>__<tool>` (same double-underscore prefix as pi)
- **Mapping from pi:** `find` → `Glob`, `ls` → (use `Glob` or `Bash`), `read` → `Read`, `write` → `Write`, `edit` → `Edit`, `grep` → `Grep`, `bash` → `Bash`

## Example (generic placeholder: `my-agent.md`)

```markdown
---
name: my-agent
description: >-
  <one-paragraph description of what this agent does; used for auto-routing>
tools: Read, Write, Edit, Grep, Glob, Bash, WebSearch, WebFetch, mcp__<server>__<tool>, mcp__<server>__<other_tool>
model: inherit
---

<agent body / system instructions here>
```

> **Format reference only** — `my-agent` is a placeholder documenting the file's shape. Real derived files are generated by the transformation hook from the canonical `.pi.md` sources under `agents/` (see AGENTS.md for the mandatory filename prefix).

## Tool whitelisting

Strictly enforced. Same isolation model as pi.

## Transformation from pi canonical

| pi | Claude Code |
|----|-------------|
| `read` | `Read` |
| `write` | `Write` |
| `edit` | `Edit` |
| `grep` | `Grep` |
| `find` | `Glob` |
| `ls` | `Glob` (or `Bash ls`) |
| `bash` | `Bash` |
| (n/a) | `WebSearch`, `WebFetch` (claude-only built-ins) |
| `mcp__server__tool` | `mcp__server__tool` (unchanged) |
| `model:` omitted | `model: inherit` (keyword valid) |

## Gotchas

- TitleCase is mandatory — lowercase `read` fails silently.
- `model: inherit` works here (unlike pi where it must be omitted).
- Extra built-ins `WebSearch`/`WebFetch` not available in pi — skip when reverse-deriving.
